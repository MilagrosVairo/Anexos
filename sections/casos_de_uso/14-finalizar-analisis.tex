\subsubsection{Finalizar Análisis (Todos los tipos)}

\textbf{Descripción:} El usuario finaliza un análisis completado, cambiando su estado según el rol. Los Analistas envían a aprobación, los Administradores aprueban directamente.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item El análisis debe estar en estado \texttt{EN PROCESO}.
    \item Debe existir suficiente evidencia registrada según el tipo de análisis (ver validaciones específicas).
    \item El usuario debe estar autenticado.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item Si es Analista: análisis pasa a \texttt{PENDIENTE APROBACION}.
    \item Si es Administrador: análisis pasa directamente a \texttt{APROBADO}.
    \item Fecha de fin automática asignada.
    \item Registro en historial de análisis.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Analista, Administrador.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
    \item El usuario accede al detalle de un análisis en estado \texttt{EN PROCESO}.
    \item Verifica que el análisis esté completo.
    \item Selecciona ``Finalizar análisis''.
    \item El sistema valida que haya evidencia suficiente:
    \begin{itemize}[nosep]
        \item \textbf{Pureza:} Datos de pesos, datos INASE o listados.
        \item \textbf{PMS:} Al menos una tanda con CV válido.
        \item \textbf{Germinación:} Al menos una tabla con repeticiones completas.
        \item \textbf{Tetrazolio:} Todas las repeticiones esperadas completadas.
        \item \textbf{DOSN:} Datos INIA completos.
    \end{itemize}
    \item Si la validación es exitosa:
    \begin{itemize}[nosep]
        \item Analista: cambia estado a \texttt{PENDIENTE APROBACION}.
        \item Administrador: cambia estado a \texttt{APROBADO}.
        \item Asigna fecha de fin automáticamente (fecha actual).
        \item Registra el cambio en el historial.
        \item Muestra mensaje de confirmación según rol:
        \begin{itemize}[nosep]
            \item Analista: ``Análisis enviado a aprobación exitosamente''.
            \item Administrador: ``Análisis aprobado exitosamente''.
        \end{itemize}
    \end{itemize}
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Análisis sin evidencia suficiente (Pureza)}
\begin{itemize}[nosep]
    \item El sistema detecta falta de datos.
    \item Muestra error: ``No se puede finalizar: el análisis de Pureza carece de evidencia. Agregue datos de pesos, datos INASE o listados antes de finalizar''.
    \item Bloquea finalización.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Análisis sin evidencia suficiente (PMS)}
\begin{itemize}[nosep]
    \item El sistema detecta que no hay tandas con CV válido.
    \item Muestra error: ``No se puede finalizar: debe tener al menos una tanda con CV válido''.
    \item Bloquea finalización.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A3. Análisis sin evidencia suficiente (Germinación)}
\begin{itemize}[nosep]
    \item El sistema detecta que no hay tablas completas.
    \item Muestra error: ``No se puede finalizar: debe tener al menos una tabla de germinación con repeticiones completas''.
    \item Bloquea finalización.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A4. Análisis sin evidencia suficiente (Tetrazolio)}
\begin{itemize}[nosep]
    \item El sistema detecta repeticiones incompletas.
    \item Muestra error: ``No se puede finalizar: faltan repeticiones por completar''.
    \item Bloquea finalización.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A5. Análisis sin evidencia suficiente (DOSN)}
\begin{itemize}[nosep]
    \item El sistema detecta datos INIA incompletos.
    \item Muestra error correspondiente.
    \item Bloquea finalización.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A6. Intentar finalizar análisis ya finalizado}
\begin{itemize}[nosep]
    \item El sistema detecta que no está en \texttt{EN PROCESO}.
    \item Muestra error: ``Este análisis ya ha sido finalizado''.
    \item No permite la acción.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Validación específica de evidencia según tipo de análisis.
    \item Fecha de fin automática (fecha actual).
    \item Estado final depende del rol del usuario.
    \item Registro automático en historial con usuario y fecha.
    \item No reversible (estado solo cambia por aprobación/rechazo).
\end{itemize}
