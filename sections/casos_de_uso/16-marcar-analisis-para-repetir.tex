\subsubsection{Marcar Análisis para Repetir}

\textbf{Descripción:} El Administrador marca un análisis como "A REPETIR" cuando no cumple con los estándares de calidad, permitiendo crear un nuevo análisis del mismo tipo para el lote. El análisis marcado queda como referencia histórica.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item El análisis debe estar en estado "PENDIENTE APROBACION" o "APROBADO".
    \item El usuario debe tener rol Administrador.
    \item Se detectaron problemas de calidad, errores en datos o inconsistencias metodológicas.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item El análisis cambia a estado "A REPETIR".
    \item Se habilita la creación de un nuevo análisis del mismo tipo para el lote.
    \item El análisis marcado queda como referencia histórica (solo lectura).
    \item Se registra la acción en el historial con usuario, fecha y motivo/observaciones.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Administrador.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
    \item El Administrador accede al detalle de un análisis.
    \item Revisa el análisis y detecta problemas (errores en datos, incumplimiento de estándares, resultados inconsistentes, problemas metodológicos).
    \item Selecciona la acción "Marcar para repetir".
    \item El sistema muestra un diálogo de confirmación con texto explicativo:
    \begin{itemize}[nosep]
        \item "¿Está seguro de marcar este análisis para repetir?"
        \item "Esto permitirá crear un nuevo análisis del mismo tipo"
        \item Campo opcional para ingresar motivo/observaciones.
    \end{itemize}
    \item El Administrador confirma y opcionalmente ingresa el motivo.
    \item El sistema:
    \begin{itemize}[nosep]
        \item Cambia el estado del análisis a "A REPETIR".
        \item Registra el motivo y la acción en el historial (usuario, rol, fecha, observaciones).
        \item Habilita la opción de crear un nuevo análisis del mismo tipo para el lote (el lote vuelve a ser elegible para ese tipo de análisis).
        \item Muestra confirmación: "Análisis marcado para repetir. Ahora puede crear un nuevo análisis".
    \end{itemize}
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Marcar análisis APROBADO para repetir}
\begin{itemize}[nosep]
    \item Si el análisis está en estado "APROBADO", el sistema muestra una advertencia adicional: "ATENCIÓN: Este análisis está APROBADO. Marcarlo para repetir lo invalidará como resultado oficial".
    \item Requiere confirmación adicional por parte del Administrador.
    \item Si confirma, procede como en el flujo principal.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Usuario cancela la acción}
\begin{itemize}[nosep]
    \item El Administrador cierra el diálogo o selecciona "Cancelar".
    \item No se realiza ningún cambio; el análisis mantiene su estado actual.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A3. Ya existe otro análisis activo del mismo tipo}
\begin{itemize}[nosep]
    \item El sistema verifica si hay otro análisis en progreso del mismo tipo para el lote.
    \item Muestra advertencia: "Ya existe otro análisis de [TIPO] en proceso para este lote".
    \item Permite continuar (el sistema puede aceptar múltiples análisis históricos), pero informa al usuario.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A4. Usuario sin permisos}
\begin{itemize}[nosep]
    \item Si el usuario no es Administrador, la acción "Marcar para repetir" no aparece en la interfaz.
    \item Si intenta acceder por URL directa, el sistema responde con error 403 (Acceso denegado).
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Solo Administradores pueden marcar un análisis como "A REPETIR".
    \item Puede aplicarse a análisis en "PENDIENTE APROBACION" o "APROBADO".
    \item Requiere confirmación explícita y, opcionalmente, motivo/observaciones.
    \item El análisis marcado no se elimina; permanece como referencia histórica y queda en solo lectura.
    \item La acción habilita automáticamente la creación de un nuevo análisis del mismo tipo para el lote.
\end{itemize}
