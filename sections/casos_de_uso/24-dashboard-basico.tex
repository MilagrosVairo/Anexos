\subsubsection{Obtener métricas agregadas de análisis}

\textbf{Descripción:} El sistema calcula totales por estado y cantidad de análisis aprobados en la fecha actual para mostrar indicadores rápidos.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item Registros de análisis existentes.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item DTO con conteos por estado y aprobados hoy devuelto.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Administrador, Analista, Observador.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
    \item Usuario solicita métricas.
    \item Servicio consulta repositorios \texttt{countByEstado} y \texttt{countCompletadosEnFecha}.
    \item Agrega resultados en estructura Stats.
    \item Retorna respuesta.
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Sin análisis}
\begin{itemize}[nosep]
    \item Retorna ceros en todos los campos.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Error de repositorio}
\begin{itemize}[nosep]
    \item Se propaga excepción (manejo según capa superior).
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Conteos: ``EN PROCESO'', ``PENDIENTE APROBACION'', ``APROBADO'', ``A REPETIR''.
    \item Conteo diario de aprobados (hoy).
    \item Sin gráficos ni tendencias históricas avanzadas.
\end{itemize}
