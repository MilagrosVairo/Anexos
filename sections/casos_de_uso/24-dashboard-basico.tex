\subsubsection{Obtener métricas agregadas de análisis}

\textbf{Descripción:} El sistema calcula totales por estado y la cantidad de análisis aprobados en la fecha actual para mostrar indicadores rápidos en un dashboard o widget.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item Existen registros de análisis en el sistema.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item Se devuelve un DTO con los conteos por estado y el conteo de aprobados hoy.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Administrador, Analista, Observador.

\vspace{0.5em}
\noindent\textbf{Flujo de evento principal:}
\begin{enumerate}[nosep]
    \item El usuario solicita métricas (por ejemplo, desde un endpoint o widget del dashboard).
    \item El servicio de métricas consulta los repositorios correspondientes (por ejemplo: \texttt{countByEstado} y \texttt{countCompletadosEnFecha}).
    \item El servicio agrega los resultados en una estructura \texttt{StatsDTO} con campos: conteo por estado y aprobados hoy.
    \item Se retorna la respuesta al cliente con los datos listos para mostrar en UI.
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Sin análisis}
\begin{itemize}[nosep]
    \item Si no existen análisis, el sistema devuelve ceros en todos los campos del DTO.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Error de repositorio}
\begin{itemize}[nosep]
    \item Si ocurre una excepción al consultar el repositorio, la excepción se propaga y se maneja según la capa superior (controlador/middleware).
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Conteos por estado: \texttt{EN_PROCESO}, \texttt{PENDIENTE_APROBACION}, \texttt{APROBADO}, \texttt{A_REPETIR}.
    \item Conteo diario de aprobados (fecha actual) para mostrar un valor de "aprobados hoy".
    \item Respuesta ligera (DTO) sin datos de series históricas ni gráficos complejos.
\end{itemize}
