\subsubsection{Generar archivo Excel con datos de lotes y análisis aplicando filtros}

\textbf{Descripción:} El usuario solicita exportar resultados filtrados y el sistema genera un archivo XLSX con encabezados, subencabezados y filas de datos según DTO de exportación.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item Usuario autenticado.
    \item Existen registros para los filtros o IDs solicitados.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item Archivo Excel generado en memoria y ofrecido para descarga.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Observador, Analista, Administrador.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
    \item Usuario dispara acción ``Exportar Excel'' desde la pantalla de resultados.
    \item Frontend envía \texttt{loteIds} o estructura de filtros (\texttt{ExportacionRequestDTO}).
    \item Backend obtiene datos (DTO consolidado) según filtros.
    \item Construye workbook (encabezados, subencabezados, filas).
    \item Ajusta estilos básicos y autoajuste de columnas.
    \item Retorna bytes XLSX para descarga inmediata.
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Sin datos}
\begin{itemize}[nosep]
    \item Genera archivo con solo encabezados.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. IDs inválidos}
\begin{itemize}[nosep]
    \item Backend omite inexistentes y continúa, o lanza error si todos son inválidos.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A3. Error de E/S al generar}
\begin{itemize}[nosep]
    \item Se retorna mensaje de fallo y no se entrega archivo.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Solo formato Excel.
    \item Encabezados y subencabezados definidos en servicio.
    \item Filtrado avanzado soportado por solicitud (\texttt{obtenerDatosConFiltros}).
\end{itemize}
