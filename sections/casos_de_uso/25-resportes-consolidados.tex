\subsubsection{Generar métricas consolidadas (general y por tipo) en un periodo, incluyendo consultas de contaminantes por especie}

\textbf{Descripción:} Se unifica la obtención de métricas en DTOs reales para: General, Pureza, PMS, Germinación, Tetrazolio y DOSN. También se exponen contaminantes por especie para Pureza/DOSN.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
   \item Usuario autenticado con permisos de lectura.
   \item Fechas inicio/fin opcionales; si se incluyen, inicio<=fin.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
   \item DTO(s) retornados con estructuras pobladas; métricas en cero/mapas vacíos si no hay datos.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Administrador, Analista.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
   \item Usuario selecciona periodo (fechaInicio, fechaFin) o deja ambas null para histórico completo.
   \item Frontend solicita al backend los reportes necesarios por pantalla.
   \item Servicio valida coherencia de fechas.
   \item Para cada tipo:
   \begin{enumerate}[nosep]
      \item Invoca repositorios filtrando por rango temporal.
      \item Agrega/agrupa (por especie/estado) y calcula promedios/porcentajes.
      \item Construye el DTO correspondiente.
   \end{enumerate}
   \item Para el general agrega datos transversales (estados, totales, tiempos, top problemas).
   \item Retorna DTOs para visualización consolidada.
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Fechas null (ambas)}
\begin{itemize}[nosep]
   \item Se consideran todos los registros.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Solo una fecha enviada}
\begin{itemize}[nosep]
   \item Se interpreta como límite abierto.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A3. Rango sin datos}
\begin{itemize}[nosep]
   \item Totales a cero y mapas vacíos; sin error.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A4. Especie sin coincidencias}
\begin{itemize}[nosep]
   \item Mapa vacío (200 OK).
\end{itemize}

\vspace{0.3em}
\noindent\textit{A5. Inicio>fin}
\begin{itemize}[nosep]
   \item Resultado vacío o error de validación según implementación.
\end{itemize}
