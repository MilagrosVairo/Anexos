\subsubsection{Consultar registros con filtros combinados}

\textbf{Descripción:} El usuario aplica filtros (estado, tipo de análisis, rango de fechas, rol, atributos del lote) y obtiene resultados paginados y ordenados.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item Usuario autenticado (Observador, Analista o Administrador).
    \item Existen registros en la entidad consultada.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item Se devuelve página de resultados con total global para continuar navegando.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Observador, Analista, Administrador.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
    \item Usuario abre listado (lotes, análisis, usuarios).
    \item Selecciona filtros (ej: estado = \texttt{PENDIENTE\_APROBACION}, tipo = \texttt{GERMINACION}, fecha inicio entre dos fechas).
    \item Define página (campo).
    \item Frontend envía parámetros al backend.
    \item Backend construye query (ej Specifications) y ejecuta paginación.
    \item Devuelve lista, total, número de página y tamaño.
    \item Usuario navega páginas o refina filtros.
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Sin resultados}
\begin{itemize}[nosep]
    \item Retorna lista vacía y total 0.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Filtros inválidos}
\begin{itemize}[nosep]
    \item Formato fechas incorrecto: backend rechaza.
    \item Se muestra error.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A3. Página fuera de rango}
\begin{itemize}[nosep]
    \item Backend ajusta a última página o devuelve vacío.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Filtros por estado (\texttt{EN\_PROCESO}, \texttt{PENDIENTE\_APROBACION}, \texttt{APROBADO}, \texttt{A\_REPETIR}) y activos/inactivos.
    \item Filtros por tipo de análisis (\texttt{PUREZA}, \texttt{PMS}, \texttt{GERMINACION}, \texttt{TETRAZOLIO}, \texttt{DOSN}).
    \item Paginación con total.
    \item Orden por al menos un campo.
\end{itemize}
