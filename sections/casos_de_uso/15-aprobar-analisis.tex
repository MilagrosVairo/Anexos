\subsubsection{Aprobar Análisis Pendiente}

\textbf{Descripción:} El Administrador revisa y aprueba un análisis que está en estado \texttt{PENDIENTE APROBACION}, cambiándolo a estado oficial \texttt{APROBADO}.

\vspace{0.5em}
\noindent\textbf{PreCondiciones:}
\begin{itemize}[nosep]
    \item El análisis debe estar en estado \texttt{PENDIENTE APROBACION}.
    \item El usuario debe tener rol \texttt{ADMIN}.
    \item El análisis debe cumplir con estándares de calidad.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{PostCondiciones:}
\begin{itemize}[nosep]
    \item Análisis cambia a estado \texttt{APROBADO}.
    \item Se marca como análisis oficial del lote.
    \item Registro en historial de cambios.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Actores:} Administrador.

\vspace{0.5em}
\noindent\textbf{Flujo de eventos principal:}
\begin{enumerate}[nosep]
    \item El Administrador accede al listado de análisis pendientes.
    \item Filtra por tipo de análisis (Pureza, PMS, Germinación, Tetrazolio, DOSN).
    \item Selecciona un análisis en estado \texttt{PENDIENTE APROBACION}.
    \item Revisa el detalle completo del análisis:
    \begin{itemize}[nosep]
        \item Datos registrados.
        \item Cálculos realizados.
        \item Cumplimiento de estándares.
        \item Historial de cambios.
    \end{itemize}
    \item Verifica que cumple con criterios de calidad.
    \item Selecciona ``Aprobar análisis''.
    \item El sistema valida:
    \begin{itemize}[nosep]
        \item Que esté en estado \texttt{PENDIENTE APROBACION}.
        \item Que el usuario sea Administrador.
        \item Que tenga evidencia suficiente.
    \end{itemize}
    \item Cambia el estado a \texttt{APROBADO}.
    \item Marca el análisis como oficial.
    \item Si hay otros análisis del mismo tipo para el lote $\rightarrow$ los marca como históricos/referencia.
    \item Registra la aprobación en historial.
    \item Muestra confirmación: ``Análisis aprobado exitosamente''.
\end{enumerate}

\vspace{0.5em}
\noindent\textbf{Flujos alternativos:}

\vspace{0.3em}
\noindent\textit{A1. Análisis no cumple estándares}
\begin{itemize}[nosep]
    \item El Administrador detecta problemas.
    \item En lugar de aprobar, selecciona ``Marcar para repetir''.
    \item Ver caso de uso ``Marcar Análisis para Repetir''.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A2. Análisis requiere correcciones menores}
\begin{itemize}[nosep]
    \item El Administrador edita directamente el análisis.
    \item Como es Admin, el análisis permanece \texttt{PENDIENTE APROBACION}.
    \item Guarda cambios.
    \item Luego procede a aprobar.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A3. Intentar aprobar análisis en otro estado}
\begin{itemize}[nosep]
    \item El sistema detecta que no está en \texttt{PENDIENTE APROBACION}.
    \item Muestra error: ``Solo se pueden aprobar análisis en estado \texttt{PENDIENTE APROBACION}''.
    \item Bloquea la acción.
\end{itemize}

\vspace{0.3em}
\noindent\textit{A4. Usuario sin permisos}
\begin{itemize}[nosep]
    \item El sistema detecta que no es Administrador.
    \item No muestra el botón ``Aprobar análisis''.
    \item Si intenta acceder por URL $\rightarrow$ muestra error 403.
\end{itemize}

\vspace{0.5em}
\noindent\textbf{Requerimientos especiales:}
\begin{itemize}[nosep]
    \item Solo Administradores pueden aprobar.
    \item Solo análisis en \texttt{PENDIENTE APROBACION} pueden ser aprobados.
    \item La aprobación marca el análisis como oficial.
    \item Registro detallado en historial con usuario y fecha.
    \item Notificación automática al creador del análisis (funcionalidad futura).
\end{itemize}
